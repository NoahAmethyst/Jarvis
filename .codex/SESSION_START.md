# Session Start Checklist

Use this checklist at the beginning of every Jarvis session.

- [ ] Read `.codex/README.md`.
- [ ] Read `.codex/WORKING_RULES.md`.
- [ ] Read `.codex/PROJECT_CONTEXT.md`.
- [ ] Read `.codex/NEXT_STEPS.md`.
- [ ] Run `git status --short --branch`.
- [ ] Identify pre-existing changes and avoid reverting them.
- [ ] Read task-relevant source files before editing.
- [ ] If implementation behavior changes, update tests.
- [ ] If public behavior changes, update `README.md`.
- [ ] If project understanding changes, update `.codex/PROJECT_CONTEXT.md`.
- [ ] If plan or priorities change, update `.codex/NEXT_STEPS.md`.
- [ ] Run relevant verification.
- [ ] Commit with `FIX`, `FEATURE`, or `OPTIMIZE` message format.
